Import existing certificate files

Upload a PEM certificate/full chain and its PEM private key. The bridge verifies that the key matches the certificate and converts them to the PFX file Technitium requires.

Automatic Let's Encrypt certificate via Cloudflare DNS

Uses DNS-01, so the Render/FRP service does not need port 80 or 53 for certificate issuance. Use a Cloudflare API token scoped to the relevant zone with Zone Read and DNS Edit permissions.
